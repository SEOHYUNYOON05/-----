# 힘 단위 변환기

## 프로그램 용도

숫자로 입력한 힘을 `N`, `kN`, `kgf` 사이에서 환산해 보여주는 Tkinter 데스크톱 프로그램입니다. 변환 결과는 화면에 기록으로 누적되며, `초기화` 버튼으로 입력값과 기록을 지울 수 있습니다.

환산에는 다음 기준을 사용합니다.

- `1 kN = 1000 N`
- `1 kN = 101.971621 kgf`

## 필요한 환경

- Python 실행 환경
- Tkinter 지원: Tkinter는 Python 표준 라이브러리이지만, 설치된 Python 배포판에 따라 별도 설치가 필요할 수 있습니다.
- GUI 창을 표시할 수 있는 데스크톱 환경

별도의 외부 Python 패키지는 코드에서 사용하지 않습니다. 필요한 Python 최소 버전은 코드에서 확인할 수 없습니다.

## 실행

Windows PowerShell에서 스크립트가 있는 폴더로 이동한 뒤 실행합니다.

```powershell
cd "$HOME\OneDrive\Desktop"
python .\force_converter.py
```

## 입력과 결과 예시

단위를 선택하고 숫자를 입력한 다음 `변환`을 누릅니다. Enter 키도 변환을 실행합니다.

| 입력값 | 선택 단위 | 표시되는 환산 결과 |
| ---: | :--- | :--- |
| `10` | `kN` | `10,000.00 N`, `10.0000 kN`, `1,019.72 kgf` |
| `500` | `N` | `500.00 N`, `0.5000 kN`, `50.99 kgf` |
| `25` | `kgf` | `245.17 N`, `0.2452 kN`, `25.00 kgf` |

## 오류 입력 예시

| 입력 | 동작 |
| :--- | :--- |
| 빈 입력 | 값을 입력하라는 경고를 표시합니다. |
| `abc` | 숫자를 입력하라는 경고를 표시합니다. |
| `-3` | 힘의 크기는 0 이상이어야 한다는 경고를 표시합니다. |

`0`은 유효한 입력입니다. 오류가 발생하면 경고가 결과 영역에 추가됩니다.

# CSV 분석 프로그램

## 프로그램 용도

`load_analyzer.py`는 CSV 파일의 하중 데이터를 읽고, 응력과 시간-응력 그래프를 분석해 결과를 표시하는 프로그램입니다. 원본 CSV 파일인 `load_data.csv`는 그대로 유지되고, 계산 결과는 별도의 `load_result.csv`에 저장됩니다.

## 입력 파일과 열

기본 입력 파일은 `load_data.csv`입니다. CSV에는 다음 두 열이 있어야 합니다.

- `time_s`: 시간, 단위는 `s`
- `force_N`: 하중, 단위는 `N`

예시:

```csv
time_s,force_N
0,0
1,100
2,250
3,400
```

## 단면적 설정

응력 계산은 다음 식으로 수행합니다.

```text
stress_MPa = force_N / area_mm2
```

현재 단면적은 `AREA_MM2 = 100.0`으로 설정되어 있습니다. 값을 변경하려면 `load_analyzer.py`의 `AREA_MM2` 값을 수정하면 됩니다.

## 필요한 라이브러리

- Python
- Matplotlib

Matplotlib가 설치되어 있지 않으면 다음 명령으로 설치합니다.

```powershell
python -m pip install matplotlib
```

## 실행

Windows PowerShell에서 프로그램 폴더로 이동한 뒤 실행합니다.

```powershell
cd "$HOME\OneDrive\Desktop\코딩과응용"
python .\load_analyzer.py
```

프로그램은 `load_data.csv`를 기본 입력 파일로 사용합니다.

## 출력

실행 결과에는 다음 정보가 표시됩니다.

- 데이터 개수
- 최대 하중과 해당 시간
- 최대 응력과 해당 시간
- 기준 응력 6 MPa를 초과한 데이터 개수

생성되는 파일은 다음과 같습니다.

- `load_result.csv`: `time_s`, `force_N`, `stress_MPa` 열이 포함된 계산 결과
- `stress_plot.png`: 시간-응력 그래프

## 오류 처리 규칙

CSV에서 잘못된 데이터가 발견되면 해당 행을 계산과 그래프에서 제외합니다.

- `time_s` 또는 `force_N` 값이 비어 있으면 해당 행을 제외합니다.
- `time_s` 또는 `force_N` 값이 숫자가 아니면 해당 행을 제외합니다.
- 제외된 행 번호와 문제값은 터미널에 출력합니다.
- 제외된 행 수와 유효한 데이터 수도 터미널에 출력합니다.
- 유효한 데이터가 하나도 없으면 계산을 중단하고 안내 메시지를 출력합니다.
- 원본 입력 CSV인 `load_data.csv`는 수정하지 않습니다.

`load_bad.csv`를 테스트하려면 프로그램 코드의 입력 파일 경로를 `load_bad.csv`로 변경한 뒤 실행하면 됩니다.

프로젝트 폴더에서 Windows PowerShell을 열고 다음 명령으로 GUI를 실행합니다.

Matplotlib와 Tkinter가 필요합니다. Tkinter는 Python 설치에 포함되지 않은 배포판도 있습니다. GUI 창 위쪽의 `CSV 찾아보기`로 입력 파일을 고르고, 단면 종류를 선택한 뒤 표시되는 치수 입력칸에 값을 넣습니다. `분석`을 누르면 단면적, 최대 응력과 해당 시간, 시간-응력 그래프가 표시됩니다.

### CSV 형식

CSV 첫 행에는 다음 필수 열 이름이 있어야 합니다. 열 순서는 상관없습니다.

| 열 이름 | 내용 | 단위 |
| :--- | :--- | :--- |
| `time_s` | 측정 시간 | s |
| `force_N` | 축 방향 하중 | N |

예시:

```csv
time_s,force_N
0,0
1,100
2,250
3,400
```

GUI의 파일 선택창에서 프로젝트의 `load_data.csv`, `load_bad.csv` 또는 형식에 맞는 다른 CSV를 선택할 수 있습니다.

### 단면 치수 및 면적

단면 종류를 선택하면 그 형상에 필요한 입력칸만 표시됩니다. 치수는 모두 mm, 계산된 면적은 mm²입니다.

| 단면 종류 | 입력 치수와 단면적 식 | 유효 조건 |
| :--- | :--- | :--- |
| 사각형 | 폭 `b`, 높이 `h`; `A = b × h` | `b > 0`, `h > 0` |
| 원형봉 | 직경 `d`; `A = π × d² / 4` | `d > 0` |
| 원형관 | 외경 `D`, 두께 `t`; 내경 `D − 2t`; `A = π × [D² − (D − 2t)²] / 4` | `D > 0`, `t > 0`, `2t < D` |
| 사각형관 | 바깥 폭 `B`, 바깥 높이 `H`, 두께 `t`; `A = B × H − (B − 2t) × (H − 2t)` | 모든 치수 `> 0`, `2t < B`, `2t < H` |
| H형강 | 전체 폭 `B`, 전체 높이 `H`, 웨브 두께 `tw`, 플랜지 두께 `tf`; `A = 2 × B × tf + (H − 2tf) × tw` | 모든 치수 `> 0`, `2tf < H`, `tw < B` |

### 계산에서 사용하는 이상화 가정

- 하중은 단면에 축 방향으로 작용하며, 단면 전체에 응력이 균일하게 분포한다고 가정합니다. 따라서 각 시점의 응력은 `stress_MPa = force_N / area_mm2`로 계산합니다. `N/mm²`는 `MPa`와 같습니다.
- 단면 치수와 단면적은 측정 시간 동안 일정합니다. 응력은 재료의 탄성, 항복, 좌굴, 편심 하중, 응력 집중이나 시간에 따른 단면 변화를 모델링하지 않습니다.
- 원형관은 동심원이고 일정한 두께의 관으로 계산합니다.
- 사각형관은 바깥 직사각형에서 사방 두께 `t`인 안쪽 직사각형을 뺀 단면으로 계산합니다.
- H형강 식은 폭 `B`가 같은 위·아래 플랜지와 중앙의 직사각형 웨브로 구성된 대칭 단면을 뜻합니다. 필릿과 모서리 곡률은 포함하지 않습니다.

### 오류와 데이터 상태 처리

- 필수 CSV 열 `time_s` 또는 `force_N`가 없으면 누락된 열 이름을 오류 안내로 표시합니다.
- 필수 열의 행 값이 비어 있거나 숫자로 변환되지 않으면 해당 행을 제외하고 유효 데이터 수와 제외 데이터 수를 표시합니다. `load_bad.csv`에서는 2초 하중이 비어 있고 3초 하중이 `abc`이므로 유효 데이터 8개, 제외 데이터 2개가 됩니다.
- 유효 데이터가 0개이면 분석을 중단하고 안내합니다.
- 치수가 비어 있거나 숫자가 아니거나 0 이하이면 안내하고 계산하지 않습니다. 원형관의 `2t < D`, 사각형관의 `2t < B` 및 `2t < H`, H형강의 `2tf < H` 및 `tw < B` 조건을 위반해도 분석을 중단합니다.
- CSV를 새로 선택하거나 단면 종류 또는 치수를 바꾸면 이전 단면적·응력·그래프 결과는 무효가 되고 다시 분석해야 합니다. 오류가 발생해도 이전 결과를 현재 결과처럼 남기지 않습니다. 입력을 바로잡고 `분석`을 누르면 결과를 다시 계산합니다.
- `load_data_peak_test.csv`는 원본 데이터의 복사본에서 7초 하중을 `900 N`으로 바꾼 예시입니다. 이 CSV와 사각형 `b=10 mm`, `h=10 mm`를 사용하면 최대 응력은 `9 MPa`, 해당 시간은 `7 s`입니다.
